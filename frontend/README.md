# React Frontend (Planned)

The frontend will be bootstrapped with Vite + React and will consume the Django API in `../backend`. Planned features include:

- Authentication views for login and registration
- Dashboard summarizing bases and analytics
- Spreadsheet-like editors powered by TanStack Table
- Charting with Plotly.js
- TailwindCSS driven UI components

> Tip: After installing dependencies, create a `.env` file with `VITE_API_URL=http://localhost:8000` to connect to the backend.
